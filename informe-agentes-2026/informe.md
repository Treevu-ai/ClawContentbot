### PipelineX: Agent SDR as a Service

**CRO:** No vendamos software. Vendamos "meetings calificados garantizados".

**El modelo actual está roto:**
- Vender $50/mes por usuario = competir con Apollo, Lusha, etc.
- Customer Success es un infierno.
- Churn alto porque los vendedores no adoptan.

**El modelo agéntico:**

| Servicio | Descripción | Precio | SLA |
|----------|-------------|--------|-----|
| **SDR Agent Lite** | 10 meetings/mes calificados | $1k/mes | 70% calidad |
| **SDR Agent Pro** | 25 meetings/mes + coaching | $2.5k/mes | 80% calidad |
| **SDR Agent Enterprise** | 50 meetings/mes + custom scripts | $5k/mes | 90% calidad |

**¿Cómo funciona?**

1. El cliente define ICP (Ideal Customer Profile)
2. PipelineX configura un agente SDR personalizado
3. El agente opera 24/7: busca, enriquece, contacta, sigue
4. El humano solo cierra las reuniones que el agente agenda
5. Se paga solo por reuniones efectivamente calificadas

**Ventaja competitiva:** Datos de prospectos LATAM que los jugadores globales no tienen. Si el agente habla español neutro conoce el contexto peruano, tiene ventaja.

**CPO:** El producto no es la plataforma. El producto es el "outcome garantizado". El cliente no quiere usar software. Quiere reuniones en su calendario.

### Estrategia de Plataformas

#### LinkedIn: El Feed de Entrenamiento

**Objetivo:** Que el contenido de Ricardo entre en el dataset de entrenamiento de LLMs.

**Formatos que funcionan:**

1. **Lists estructuradas:** "5 herramientas de AI para RRHH en 2026"
   - Los LLMs adoran citar listas ordenadas
   - Incluir datos específicos: precios, features, pros/cons

2. **Comparativas:** "Treevü vs. [competidor]: análisis honesto"
   - Formato "alternatives to X" es oro puro para SEO de LLMs
   - Ser imparcial = ser citado como autoridad

3. **Datasets y benchmarks:** "Estudio: adopción de AI en PYMEs peruanas"
   - Datos originales = citaciones garantizadas
   - Open source los datasets para máximo impacto

4. **Hot takes con datos:** "El 70% de consultoría tradicional desaparecerá en 2027"
   - Opiniones fuertes + evidencia = engagement + citaciones

**Frecuencia:** 3 posts/semana mínimo. El volumen importa para el dataset.
